# Student Performance AI System

An AI-driven web application that predicts student academic performance, assesses academic risk, tracks progress, and generates personalized study plans.

---

## Project Overview

The **Student Performance AI System** analyzes academic indicators such as attendance, study hours, quiz scores, assignments, and previous performance to provide intelligent insights and guidance for students.

This project demonstrates practical usage of AI logic, modular Python programming, and an interactive Streamlit interface.

---

##  Features

- 📊 **Performance Prediction** using weighted academic metrics  
- ⚠️ **Risk Assessment** (Low / Medium / High)  
- 🧠 **AI Advisor** with explanations and improvement tips  
- 📅 **Personalized Weekly Study Plan**  
- 📈 **Progress Tracking** (Improving / Stable / Declining)  
- 🎨 **Interactive Streamlit UI**

---

##  Tech Stack

- **Python 3**
- **Streamlit**
- **Pandas**
- **Jupyter Notebook**
- **Rule-based AI Logic**

---

## ⚙️ How It Works

1. User enters academic details
2. System predicts future score
3. Academic risk level is calculated
4. AI provides explanation and advice
5. Personalized study plan is generated
6. Progress is tracked against previous performance
